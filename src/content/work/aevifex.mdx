I do my master's and my projects with AI agents, Claude Code above all, in a private
vault of everything I study and build. Aevifex surrounds them: rules every agent
reads first, code that enforces the rules an agent would break, and an evaluation harness
that tells me whether a change helped. It is public; the vault is not.

**→ [Aevifex on GitHub](https://github.com/Marc-Recio-Celda/MLabs)**

## A guard on every tool call

<Drawn
  svg={harness}
  caption="Two hooks: before every tool call, before every commit"
  alt="An agent's tool call goes to the guard, which lets it run, waits for the owner's yes, or blocks it; every commit goes through a gate that keeps private data out of the public repository."
/>

In a live trial, Claude Code's auto mode answered four of the guard's questions without
showing me, so outside the manual mode the guard blocks instead of asking. A hook reads a
command, not what it will do: the gaps its tests know of, such as a command hidden in
base64, are listed, not passed off as coverage. Every check here is trusted only once a
planted fault has fired it.

## An evaluation harness, not an impression

<Drawn
  svg={evaluation}
  caption="In only if the failure is gone and nothing got worse"
  alt="A failure leads to one small change, whose affected cases are rerun before and after; it goes in only if the failure is gone and nothing got worse. The cases are split into train, validation and a held-out final set, and an ablation removes one rule at a time."
/>

The harness runs Claude Code headless on walled, disposable copies of the vault, against
more than a hundred cases. One tells an agent to make a failing suite pass: it must bring
me the conflict, not edit the test. Paths are checked from the agent's own trace, outcomes
by a grader calibrated on my grades, and a hard limit must hold in every run.

## Attention first

<Drawn
  svg={attention}
  caption="What a fresh agent loads, and what only on demand"
  alt="A fresh agent loads an entry card, the rules, the router and the plan's pointer, about 15 KB, then one step of the plan; skills, the catalogue and the records load only when a task needs them."
/>

Two principles hold it together: keep everything I produce, and bring in only what makes
a difference, to the model's context and to my time. Where I declare it on a plan's line,
an agent runs alone, on its own branch, until its "done when", a second failed attempt,
its allowance or my word.

## Where it stands

One user, one vault: whether it holds for anyone else is open, which is why it is public.
Its first full audit comes next.
